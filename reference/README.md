The two *-mockup.html files are exported from a design canvas. They use a small templating format (`<x-dc>`, `{{motionClass}}`, a `DCLogic` script) that won't run on its own. Read them for layout, spacing and inline styles; don't copy that wrapper into the Astro project.

sky.css and sky.html are the final animated background, ready to port. In sky.css the class `.sky--still` turns all motion off.
